# 目录结构说明

```text
src/scdw/                 正式 Python 包
data/rag/                 人工维护的 XML 模板与元数据
data/xlsx/                XLSX 样例与模板
data/generated/           运行生成 XML，不是源码
assets/tia_projects/      保留的 TIA Portal 工程资产
tests/unit/               无 TIA 环境可运行的基础测试
tests/integration/        需要 TIA 或外部环境的集成测试
archive/experiments/      Notebook、旧实验说明等历史实验
archive/legacy_assets/    旧工程副本与压缩备份
docs/                     中文设计、资产与开发说明
```

新增 Python 代码必须放入 `src/scdw/` 的现有职责包；不要重新在根目录创建 `core/`、`RAG/`、`frontend/` 或 `openness/` 作为正式代码目录。人工维护模板放入 `data/rag/templates/<分类>/`，模型生成 XML 只能写入 `data/generated/`。不确定的资产先放入 `archive/` 并更新资产清单。
