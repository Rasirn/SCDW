启动 GUI 后，打开最新 `data/logs` 子目录，依次查看 `manifest.json`、`session.jsonl`、`conversation.md`、`mcp/mcp.jsonl` 和 `tia/tia_operations.jsonl`。用 `conversation_id`、`turn_id`、`round`、`tool_call_id` 过滤即可还原一次请求到模型、工具及 TIA 的链路。
